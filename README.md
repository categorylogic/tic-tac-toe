# Tic-Tac-Toe

Simple terminal Tic-Tac-Toe game written in Python.

## Requirements
- Python 3.10+

## Run the game
```bash
python tic_tac_toe.py
```

You can choose to play against another person or against the built-in computer opponent. Follow the prompts to enter moves using positions 1-9 shown on the board.
